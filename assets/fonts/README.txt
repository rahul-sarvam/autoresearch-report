Autoresearch report — self-hosted typefaces

Inter, Newsreader and IBM Plex Mono are distributed under the SIL Open Font
License 1.1. The unmodified license and copyright texts are included beside
these font files as inter-OFL.txt, newsreader-OFL.txt and ibmplexmono-OFL.txt.

Latin webfont subsets were downloaded from the official Google Fonts CSS API
on 9 November 2026. They are served locally; the report makes no runtime
requests to Google Fonts. Font names are not changed.

Official source and license locations:
https://github.com/google/fonts/tree/main/ofl/inter
https://github.com/google/fonts/tree/main/ofl/newsreader
https://github.com/google/fonts/tree/main/ofl/ibmplexmono
